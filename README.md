# CampusDesk AI 🎓
### A Smart Academic Organization and Student Assistance Platform

CampusDesk AI is a student-focused web application designed to simplify academic management by bringing essential academic activities together on a single platform. It aims to help students organize attendance, assignments, deadlines and study materials through a centralized and user-friendly dashboard.

---

## 📌 Project Overview

Students often use multiple applications and manual methods to manage their academic responsibilities. This can make it difficult to track attendance, remember assignment deadlines and organize study materials.

CampusDesk AI aims to address these challenges by providing a unified academic management platform that improves organization, accessibility and student productivity.

## 🎯 Objectives

- Provide a centralized platform for academic management.
- Simplify subject-wise attendance tracking.
- Help students organize assignments and deadlines.
- Provide structured access to academic notes.
- Improve academic planning and time management.
- Create a foundation for AI-powered academic assistance.

## ✨ Key Features

### 1. Smart Dashboard
- Centralized academic overview.
- Easy navigation between different modules.
- Quick access to academic information.

### 2. Attendance Manager
- Subject-wise attendance management interface.
- Attendance percentage calculation.
- Attendance target monitoring.

### 3. Assignment Manager
- Organize academic assignments.
- Track submission deadlines.
- Manage task completion status.

### 4. Notes Library
- Organize study materials by subject.
- Provide a structured interface for academic resources.

### 5. AI Academic Assistant – Planned Enhancement
- Academic concept explanations.
- AI-powered notes summarization.
- Practice questions and MCQ generation.
- Student query assistance through an AI API.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

**1. Clone the Repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the Project Folder**

```bash
cd CampusDesk-AI
```

**3. Install Dependencies**

```bash
npm install
```

**4. Start the Development Server**

```bash
npm run dev
```

**5. Open in Browser**

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

**6. Build for Production**

```bash
npm run build
```

*Note: These commands assume the project uses the standard Vite npm scripts.*
